# E-Commerce Sales & Business Performance Dashboard

## Project Overview

This project was completed as part of the **Data Analytics & Business Intelligence Internship – Task 1**.

The objective of this project is to analyze e-commerce sales data using **Microsoft Excel** and present key business performance insights through data cleaning, analysis, Pivot Tables, charts, and a dashboard.

## Tools Used

- Microsoft Excel
- Excel Functions
- Excel Tables
- Pivot Tables
- Pivot Charts
- Charts and Visualizations
- Conditional Formatting

## Dataset

The dataset contains **34,500 e-commerce transaction records**.

The data includes information such as:

- Order ID
- Customer ID
- Product ID
- Category
- Price
- Discount
- Quantity
- Payment Method
- Order Date
- Delivery Time
- Region
- Returned Status
- Total Amount
- Shipping Cost
- Profit Margin
- Customer Age
- Customer Gender
- Calculated Profit

## Data Preparation

The data was prepared and organized in Microsoft Excel for analysis.

The project includes:

- Data validation
- Data organization
- Calculated fields
- Profit calculation
- Monthly order analysis
- Order value classification
- Sales and profit analysis

## Workbook Structure

The Excel workbook contains the following sheets:

### Raw_Data

Contains the original transaction-level dataset.

### Cleaned_Data

Contains the prepared dataset used for analysis.

### PivotTables

Contains summarized business analysis using Pivot Tables.

### Dashboard

Contains the final dashboard with key business performance metrics and visualizations.

## Key Business Insights

### Regional Performance

The **South region** recorded the highest sales.

| Region | Sales |
|---|---:|
| South | 1,298,096.07 |
| North | 1,264,008.35 |
| West | 1,186,350.50 |
| East | 1,176,334.75 |
| Central | 940,503.38 |

### Category Performance

**Electronics** was the highest-performing category by sales.

| Category | Sales |
|---|---:|
| Electronics | 3,319,206.50 |
| Home | 1,077,681.52 |
| Sports | 629,825.54 |
| Fashion | 471,545.80 |
| Beauty | 153,019.38 |
| Toys | 132,013.80 |
| Grocery | 82,000.51 |

Electronics also generated the highest calculated profit of **3,265,273.43**.

### Monthly Sales

The highest monthly sales were recorded in **December 2024**, with sales of **278,154.19**.

### Payment Method

**Credit Card** recorded the highest sales contribution, with **2,056,787.40** in sales.

### Returns

There were **1,903 returned orders**, representing approximately **5.52%** of the total 34,500 orders.

## Business Recommendations

1. Focus on the **South region**, which generated the highest sales, and identify practices that can be applied to lower-performing regions.
2. Continue monitoring **Electronics**, as it is the largest contributor to sales and profit.
3. Use monthly sales trends to support inventory and promotional planning.
4. Evaluate business performance using both revenue and profit.
5. Monitor returned orders and investigate areas with higher return rates.
